# Общие правила проекта

Отвечай только на русском языке

## Технологический стек
- **Node.js** — среда выполнения JavaScript
- **TypeScript** — основной язык разработки (строгая типизация обязательна)
- **Playwright** — end-to-end тестирование и автоматизация браузера

## Основные принципы разработки

### 1. TypeScript
- **Всегда используй строгую типизацию** (`strict: true` в tsconfig.json)
- **Запрещено использовать `any`** — вместо этого используй `unknown` или конкретные типы
- **Все функции должны иметь явно указанные типы параметров и возвращаемого значения**
- **Используй интерфейсы и типы для описания структур данных**
- **Избегай `as` (приведения типов)** — лучше использовать type guards

```typescript
// ✅ Хорошо
interface UserData {
  id: string;
  name: string;
  email: string;
}

async function getUser(id: string): Promise<UserData> {
  // реализация
}

// ❌ Плохо
function getUser(id): any {
  // реализация
}
